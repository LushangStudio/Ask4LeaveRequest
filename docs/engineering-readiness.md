# 工程运行约束

## CI

GitHub Actions 在 main push、PR 和手动触发时执行 npm ci、格式检查、Vite 构建、Python 依赖一致性、pytest 和构建资源路由检查。Actions 仅有 contents:read 权限，不使用生产密钥。首次有效运行：ec97ee2，run 38348042990。

## 权限与 HTTP 边界

业务会话在生产中必须有 UIS 登录标记，并同时通过有效期、当前名单启用状态检查。管理员权限由 ADMIN_USER_IDS 配置；业务申请按申请人和提交时辅导员快照授权。管理员身份本身不授予查看全部请假条的权限。

写操作拒绝跨源 Origin / Sec-Fetch-Site。Cookie 使用 HttpOnly、Secure、SameSite=Strict，UIS state 使用 Lax 和独立回调路径。测试登录默认关闭且日志剔除查询参数。

实际请求体上限 4,300,000 字节，包含无 Content-Length、分块传输、伪造长度请求。单个 ASGI 客户端 IP 每 60 秒最多 600 次 API 请求，其中写入、认证、预览和带查询请求最多 120 次，超限返回 429 和 Retry-After。IP 计数只保留哈希，最多 10,000 个计数器；满载拒绝新增来源，不驱逐活跃计数器。当前生产单 worker，因此进程内计数覆盖整个服务；扩容前需将限流移到共享存储或网关。Uvicorn 仅信任 127.0.0.1 转发头，Nginx 应覆盖 X-Forwarded-For 为 remote_addr，不能信任客户端自填值。

## PDF 后台任务

生产始终使用 MySQL `pdf_jobs` 持久化队列，审批和入队在同一事务中提交。迁移 008 必须先由迁移账号执行，运行账号仍仅保留 DML 权限。演示默认同步；设置 PDF_JOB_MODE=async 可演示真实异步行为。

每个申请最多一个任务。数据库条件更新竞争领取，租约 300 秒；发布时检查租约和随机 token，失去租约的旧进程不能写入文件。整个批次 PDF 一次提交，任何一份失败都不发布半批文件。撤回可阻止正在运行的任务发布；审批状态不会因文件错误回退。

最多自动执行三次，异常重试间隔 10/20 秒；崩溃后租约到期重新领取，连续崩溃也受次数限制。耗尽后显示可手动重试。已就绪文件不会被重复生成。进程退出时停止领取，正在生成的未提交任务由租约恢复。前端每三秒刷新正在生成的任务，隐藏标签页暂停轮询。

不要用多个旧同步版本与新异步版本同时写同一数据库。回滚前停止新进程，保留任务表和业务数据，旧版已完成 PDF 不受影响。
