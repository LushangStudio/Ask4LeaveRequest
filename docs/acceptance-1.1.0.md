## 数据兼容与发布

部署前备份数据库，使用迁移账户执行 `docs/migrations/012-approval-archives.mysql.sql`。该迁移只新增表，不删除/重建现有库。旧版本已经是 revoked 的申请不自动恢复。

新版本辅导员撤回时，审批元数据、撤回原因、签名快照、旧 PDF 的 ID 和 SHA256 归档；旧 PDF 内容删除，旧 URL 永久失效。历史记录仅对原申请的授权人员可见。重审生成全新 PDF ID，并使旧后台任务失去发布权限。

回滚可切换旧 release，新增归档表可保留；已经发生的重新审批不可通过代码回滚复原，应在维护窗口结合备份处理，不能直接删除归档表。
